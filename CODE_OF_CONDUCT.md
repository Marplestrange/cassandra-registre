# Code de conduite

Ce dépôt est un lieu de travail, et un registre où l'on publie du code que d'autres installeront chez eux : la confiance y est le sujet. Pour que chacun puisse y contribuer sereinement :

- **Parlez du travail, pas de la personne.** Une critique vise un module, un code, une décision, jamais celui ou celle qui l'a écrit.
- **Soyez honnête sur ce que fait votre module.** Les permissions annoncées doivent être celles dont il se sert ; une fausse déclaration est refusée, et répétée, elle fait écarter l'éditeur.
- **Pas de harcèlement, d'insultes, de propos discriminatoires** (origine, genre, orientation, handicap, âge, religion, opinions), ni d'attaque répétée après un « non ».
- **Ne publiez rien de privé** : ni clé privée, ni secret, ni données personnelles d'autrui, ni adresses réelles de serveurs, les vôtres comme celles des autres.
- **La langue du projet est le français**, l'anglais est bienvenu : personne n'est moqué pour son orthographe.

## Ce qui arrive en cas d'écart

Les mainteneurs peuvent modifier ou masquer un commentaire, fermer une discussion, refuser une contribution, révoquer un module ou une clé d'éditeur, et écarter durablement quelqu'un qui enfreint ces règles.
On prévient d'abord quand l'écart est mince ; on ne prévient pas quand il est grave.

## Signaler un problème

Écrivez en privé à **marplestrange@cassandra.center** (objet : « code de conduite »). Le message reste confidentiel, y compris vis-à-vis de la personne visée tant que vous le souhaitez.
Une faille de sécurité ne se signale pas ici : voir [`SECURITY.md`](SECURITY.md).
